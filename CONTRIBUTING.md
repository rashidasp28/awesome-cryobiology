# Contributing to Awesome Cryobiology

Thank you for contributing.

We welcome contributions including:

- Papers
- Protocols
- Datasets
- Software tools
- Tutorials
- Open hardware
- Figures and schematics
- AI resources
- Educational content
- Conference information

## Contribution Guidelines

Please ensure:

- Resources are scientifically relevant
- Links are working
- Descriptions are concise and informative
- Duplicate entries are avoided
- Sources are reputable where possible

## Pull Requests

When submitting a pull request:

1. Explain what was added
2. Keep formatting consistent
3. Use clear commit messages
4. Add references where appropriate

## Repository Vision

This repository aims to become an open and collaborative knowledge hub for the global cryobiology community.
