# Contributing to Awesome Cryobiology

Thank you for helping build a trustworthy, reproducibility-focused resource for
the cryobiology community.

Contributions may include papers, protocols, datasets, software, AI models,
open hardware, figures, workflow guides, educational material, and community
resources.

## Before proposing a resource

1. Search the repository and open pull requests to avoid duplicates.
2. Read the [curation criteria](docs/curation-criteria.md).
3. Open the resource and verify that its link and key claims are current.
4. Identify the resource's strongest evidence classification.
5. Check access, licensing, provenance, and important limitations.

Do not copy copyrighted text, figures, data, or code into this repository
without permission. Link to the original source and write an original,
evidence-proportionate description.

## Evidence classification

Use the least mature classification that fairly describes the claim being
highlighted:

- Established: supported by peer-reviewed evidence, standards, consensus
  guidance, or independent replication
- Validated: supported by documented methods and relevant experimental or
  benchmark validation
- Reproducible: supported by public code or data, pinned dependencies, tests,
  and repeatable releases
- Preliminary: an early dataset, preprint, prototype, or author-only
  validation
- Conceptual: an educational model, simulation, design sketch, or unvalidated
  proposal

A resource may meet more than one definition. If validation is incomplete,
describe the resource conservatively rather than inferring evidence that is
not available.

## Information to include

Every proposed resource should state:

- what it is and why it is relevant;
- its evidence classification;
- what the contributor independently checked;
- a stable identifier or canonical link, such as a DOI or release URL;
- access and licensing or reuse status;
- important limitations, validation boundaries, or known failure modes;
- contributor affiliation or other conflict of interest;
- the repository section where it belongs; and
- a suggested reassessment trigger when the resource is preliminary or likely
  to change.

Use the resource-specific checks in the
[curation criteria](docs/curation-criteria.md) for papers, protocols, datasets,
software, AI models, hardware, figures, and educational material.

## Writing the entry

- Keep the description concise, factual, and understandable without marketing
  language.
- Distinguish measured data from simulations, illustrations, and predictions.
- Distinguish peer-reviewed work from preprints.
- Do not generalize a protocol or model beyond the biological system,
  acquisition conditions, or validation data reported.
- State access restrictions when a resource is paywalled, gated, or requires
  registration.
- Preserve the repository's existing Markdown structure and alphabetical or
  topical ordering.

## Pull-request workflow

1. Create a focused branch.
2. Add or update only the resources needed for the proposal.
3. Complete every applicable section of the
   [pull-request template](.github/pull_request_template.md).
4. Check Markdown rendering and every added or changed link.
5. Explain any uncertainty that a reviewer should resolve.
6. Respond to review feedback with sources or a narrower description.

One pull request should cover one coherent topic. Large link collections may
be easier to review as smaller, evidence-focused submissions.

## Privacy and responsible contribution

Do not include credentials, private datasets, personal health information,
precise household locations, or material that lacks the required consent or
ethical permission. De-identification does not replace consent, data-use
conditions, or institutional requirements.

## Review outcomes

A proposal may be accepted, revised, deferred, or declined. Deferral is
appropriate when evidence, licensing, provenance, access, or validation cannot
yet be verified. Inclusion does not endorse every claim made by a resource.

## Repository vision

Awesome Cryobiology aims to become an open, collaborative, and
evidence-proportionate knowledge hub for the global cryobiology community.
