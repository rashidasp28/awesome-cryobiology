# Cryobiology Dataset Template

Use this template to document cryobiology, cryomicroscopy, thermal imaging, fluorescence imaging, and AI-ready datasets.

---

# Dataset Name

Provide a concise and descriptive dataset title.

---

# Description

Describe:
- biological system,
- imaging modality,
- experiment type,
- and intended applications.

---

# Biological System

Include:
- species,
- cell or tissue type,
- concentration,
- donor information where appropriate,
- and biological relevance.

---

# Imaging Information

Include:
- microscope type,
- imaging modality,
- objective,
- excitation wavelength,
- emission filters,
- detector type,
- magnification,
- and acquisition settings.

---

# Thermal Information

Include:
- cooling rate,
- warming rate,
- thermal gradient,
- storage conditions,
- and thermal sensor information.

---

# Cryoprotective Agents

Include:
- CPA type,
- CPA concentration,
- exposure time,
- and loading protocol.

---

# Dataset Structure

Describe:
- number of images,
- videos,
- annotations,
- segmentation masks,
- metadata files,
- and directory structure.

---

# Annotation Information

Include:
- annotation type,
- annotation format,
- annotation software,
- class definitions,
- and quality-control procedures.

---

- anomaly detection,
- thermal prediction.
